# WordPress Template Theme
Ce thème WordPress est construit avec [Roots Sage](https://roots.io/sage/), utilisant le moteur de templates Laravel Blade pour une structure moderne et modulaire.  
Le workflow inclut une organisation orientée composants, une gestion avancée des assets via Laravel Mix, et une séparation claire entre logique PHP et présentation.  
Prévoyez d'utiliser Composer pour les dépendances PHP et npm/yarn pour les assets front-end.  
Une connaissance de Blade, de la structure MVC, et des outils modernes de développement WordPress (ACF, WP-CLI, etc.) sera un atout pour travailler efficacement sur ce projet.

## Configuration

### PHP
- Version: **8.2.28**

### Node.js
- Version: **22.14.0**

## Compilation du projet
```bash
composer install
npm install
npm run dev
```
